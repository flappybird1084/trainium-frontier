## Tooling, box rules, hazards
- Simulator `.venv-nki` (nki 0.5 + neuronx-cc wheels from the box): `nki.simulate(kernel)(tensors)`. Box tools `trn2_job.sh` /
  `trn2_queue.sh` / `trn2_run.sh` / `trn2_profile_neff.sh` (see `findings/tools.md`); queue files `~/tf/runs/queue_NKI*.txt` are edited
  IN PLACE - **never mv, never overwrite a running script**; sync the local `trn2_queue.sh` (WAIT fix) only at a restart. No CPU-heavy
  work (neuron-profile view) on the box during a screen.
- Tracer rules: no list comprehensions; no tuple-unpacking loops; only module globals visible (rule 4 = all kernels under one guarded
  `try: import nki` block); **128-row-aligned DMAs only inside custom ops; no strided-pattern OUTPUT DMAs (strided loads OK)**; memory
  `nki-tracer-rules` holds 1-10.
- `trn2_job.sh` refuses a job if ANY process cmdline matches `submission_v[0-9]*_.*\.py` (including the ssh `bash -c` wrapper that
  started the queue runner) - start runners from a command that never spells a submission filename; write the queue file first.
- Disk incident 06:40 UTC Sep 8: the box filled (out_* dirs + profiler dumps + 9,921 stale /tmp/nki_* build dirs) and a compile died;
  `trn2_run.sh` now clears stale builds and refuses < 15 GB. Another project's memory pressure on the local box kills long background
  waiters - poll with short loops.

## Update Sep 7 - the optimizer phase and the embedding backward (the graph's waste)
- Batch 65k tokens/step (two 4-row micro-steps, LRs x sqrt2) = 1.086675 @1675 vs 1.095337 @2781 (-0.0087 at 900 s).
- **S_C8_PROF: fwd_bwd 0.208 / grad_sync 0.027 / optimizer 0.073 s of a 0.307 s step.** `nki_opt_bench.py` (MB_OPT, one core, LNC=1)
  attributes the optimizer's 56 ms: **28 ms = the 8 tiny scalar params through eager torch AdamW (~3.5 ms each, ~9 launches per
  param)**, 16 ms = NKI AdamW over the tables (bigram 2^17x512 alone 10 ms, ~200 GB/s), 14 ms = NKI Muon (4.2/4.5/5.1 ms per stack);
  host syncs nil (0.04 ms), torch fallback 145 ms. New knob `OPT_SHARD`: expected -0.02 / -0.04 s/step.
- **Ablation proved the one-hot lowering** (600 s, fwd_bwd per 131k step): 0.860 with bigram 2^17 / 0.705 at 2^14 / 0.676 with none
  - the bigram backward alone is 0.184 s of a 0.92 s step.
- **Embedding sidecar** (`EMBED=sidecar`): NKI `embed_gather` (indirect DMA; device exact, 0.17 ms per 4096 rows) +
  `embed_scatter_add` (`dma_compute` RMW); the first device test aborted the DMA (out-of-bounds "skip" padding is not honoured by RMW)
  so padding uses distinct dummy rows in a 128-row tail of the gradient buffer; expected fwd_bwd
  ~0.63 s (-25%). Full-length: depth 12 1.0392 (+0.0044, discard); warmup 50 -0.0012.
