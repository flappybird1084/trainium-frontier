## Rules learned (also in memory)
- NKI tracer/device rules 1-10 (`nki-tracer-rules`): notably #8 128-row-aligned DMAs only inside custom ops, #9 no
  strided-pattern OUTPUT DMAs (consumers read early), #10 custom-op Python bodies run only during tracing.
- Never overwrite the vehicle while a run of it is starting; confirm a queue runner actually launched (`trn2-launch-gating`).
- Never insert lines before the queue runner's current position (it re-reads by offset): append only.
- Fused compiler graphs of small-matrix chains (the DeltaNet triangular solve) are unreliable on this stack.
