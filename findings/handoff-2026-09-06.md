5. Don't call a run hung from log silence (2 min init + multi-minute compile are normal; `pgrep -af neuronx-cc` is the

## NKI attention — the scoping this era produced
Vendor kernels in the venv, callable from torch via `from torch_neuronx.nki_hop import wrap_nki; f = wrap_nki(kernel);
out = f[grid](...)` (grid = `(int(get_logical_neuron_cores()),)`; works eager and under torch.compile). Full argument
lists and semantics: `nki-kernel-playbook-2.md` ("Box-specific notes"). Essentials:
- `attention_cte` fwd takes per-query `bound_min`/`bound_max` (B*H, L, 1) = the per-query [start, end) KV range (our
  document mask, causal applied on top), plus a per-(row, head) fp32 `sink` logit added to the softmax denominator only;
  with `cache_softmax=True` it returns `neg_max`/`out_sum_recip` (`lse = -(neg_max + log(out_sum_recip))`, shape
  (B*H, 128, L/128)). seqlen must be a multiple of 128; bf16 inputs, fp32 softmax.
- `attention_bwd` returns dq/dk/dv (transposed layouts) and `dsinks` when `sinks_ref` is given.
- Modelling change required: our 4 learned k/v registers (values contribute to the output) become **one learned sink
  logit per (layer, head)**. 3090 ledger: sinks with zero values were -0.0213 (E23); learnable values added only -0.0029
  (E23b) -> cost <= ~0.003. Keep a `SINK_MODE` so the explicit path can implement the same denominator-sink math for
  CPU/CUDA evals and the causality check.
- DECISION RULE (the one that mattered): if NKI fwd+bwd is not at least ~2x faster than explicit attention at
  B=8/H=4/L=1024/E=128, attention is not where the step time goes. (It was adopted as v12+ on the eager lines; the
  attention-layout kernels that later paid came out of this work.)
- Risks handled: the portal scorer imports the file in a fresh process on a Neuron device (nkilib/torch_neuronx imports
  are fine there, but keep every NKI import guarded and the explicit fallback intact); `check_submission` forbids
  eval/exec/compile/os.system/subprocess/socket (`wrap_nki` is a normal import); checkpoint-format changes (the sink
  param) require `load_for_eval` to rebuild from `model_config` — add `sink_mode` to GPTConfig like `use_trigram`.
- Next NKI target named here: a fused MLP (c_fc + relu^2 + c_proj, fwd+bwd); vendor helpers
  `neuronxcc.nki.kernels.allocated_fused_linear` / `nkilib.experimental` worth reading first.
